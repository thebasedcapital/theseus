# + datasets 5.0.1, and equivalence fidelity is checked by asserting ppl_a reproduces to <1e-9.
#
#   .venv/bin/pip install torch --index-url https://download.pytorch.org/whl/cu130     # ~5.4 GB venv
#
# A CPU-only build is fine for gauges, canonicalisation, ledger, analysis and archcheck, none of
# which touch llama.cpp or device-sensitive perplexity.
